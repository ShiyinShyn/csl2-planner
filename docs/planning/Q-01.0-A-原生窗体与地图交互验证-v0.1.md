## 1. 产物与消费边界

| 产物 | 职责 |
|---|---|
| prototypes/q01/shell.py | 原生 QMainWindow/QGraphicsView、临时合成 GeoPackage、只读选中详情与有界资源消费 |
| prototypes/q01/__init__.py | Q 自有 PoC 包，不引入共享类型定义 |

| prototypes/q01/README.md | 运行方式、支持边界、未验证范围 |

直接消费 P 的 MapLayer、SpaceRef、ResourceRef、VersionKey 及 C0 合成 fixture；
C0 schema 为 p0-04-c0-0.1.0。Q 不扩展或替换这些共享类型。
合成 GeoPackage 使用明确 EPSG:32631 米制投影，资源记录绑定实际文件大小和 SHA-256。
绘制时北向朝上，不猜 CRS、不改单位、不自动重投影、不回写要素。
