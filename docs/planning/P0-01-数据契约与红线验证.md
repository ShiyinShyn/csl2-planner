## 1. 范围与需求追踪

原型保存在 `prototypes/p0/`，不是发布版规划软件。

| 需求 | 契约 | 验证范围 |
|---|---|---|
| D2 分区=TAZ | 仅 PlanningZone / zone_id | 单实体导入保存、唯一 ID、几何有效性、重叠拒绝 |
| D1 逐区街区 | 分区净尺度、不变快照 | 非住宅几何与拆迁权限不被 D5 误锁 |
| D5 权限 | 住宅/商住混合可覆盖，其他类型固定默认 | 构造/取值/导入/保存；非法 editable 标志不能提权 |
| D5 继承 | 系统 → 住宅用户默认 → 分区覆盖 | 类型变化停用住宅覆盖、非法数值/未知字段拒绝 |

| Q2 版本 | 显式快照 revision | 旧输入不得发布为新方案，现状对象不删除 |

## 2. 数据契约

- **PlanningZone**：唯一规范分区实体；宏观功能、净街区尺度、拆迁许可、情景覆盖共用主键。
- **ScenarioValues / DefaultCatalog**：不可变参数与版本化默认。物理字段和真实默认值未冻结，测试值全部标记 synthetic。
- **Corridor**：平面线形、完整控制半宽、目标形态、资产允许形态和可选最低标高；尚不是完整平纵断面。
- **ExistingObject**：现状足迹与可选地面/基础保护底界；未知不作零。
- **Snapshot**：同一米制空间标识、版本、规范分区、现状覆盖和硬保护。
- **TunnelRules**：版本、平面缓冲、覆土、基础间距、隧道外高度；不硬编码现实工程数值。

竖向向上为正。原型只校验空间标识一致，不宣称已验证 CRS、单位或游戏坐标映射；实际 GIS 适配是后续检查点。显式拒绝 Z 坐标混入平面足迹和线形，Shapely 的平面交叠测试不当作三维净空求解。[S1]

## 3. D7 裁决及状态

1. 检查输入版本、统一空间和独立硬保护。
2. 线路按完整控制半宽生成包络，与现状足迹和安全缓冲比较，不能仅检查中心线。
3. 对象全部被关联分区覆盖且所有分区允许拆迁时，才提拆迁候选；否则地下-only。
4. 现状覆盖/分区关联不完整或基础未知 → 资料不足；资产不支持隧道 → 无可行方案。
5. 资料充分时，局部隧道外顶低于覆土控制面与基础保护底界，扣除外高度一半得到中心标高上界。
6. 最低允许标高高于任何地下上界时 → 地下范围为空，不改地表或高架。

| 状态 | 语义 |
|---|---|
| POLICY_CLEAR | 本快照没有触发禁拆，不是完整几何或工程通过 |
| TUNNEL_REQUIRED | 强制地下、碰撞脱困 LOWER_ONLY，不是已生成可施工隧道 |
| DATA_INSUFFICIENT | 不能声明通过；已知禁拆冲突仍保留地下-only约束 |
| NO_FEASIBLE_SOLUTION | 已知硬条件下无合法候选，不放宽约束 |
| STALE_INPUT | 旧输入不能发布为当前结果 |

本轮没有实现纵坡/竖曲线求解、隧道入口出口、桥墩和地下设施三维冲突，也未验证游戏内可建造性。不得将契约测试通过说成这些能力已完成。
